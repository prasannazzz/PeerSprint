# PeerCode— Advanced Interview Platform

**PeerCode** is a **production-grade interview platform** designed to simulate **real-world technical interviews** with **live video calls, real-time chat, collaborative coding, and automated evaluation**.

Built with modern tools and best practices, this project demonstrates how large-scale interview systems are architected — from authentication and real-time communication to secure code execution and background jobs.

---

##  Why PeerCode?

Technical interviews are more than just coding — they involve **communication, collaboration, and problem-solving under pressure**.

PeerCode recreates that experience by combining:

*  Live 1-on-1 video interviews
*  Real-time chat messaging
*  VSCode-powered collaborative editor
*  Secure isolated code execution
*  Automated feedback with test cases
*  Real-time dashboards and analytics

---

##  Key Features

###  Coding Experience

* VSCode-powered in-browser code editor
* Secure execution in an isolated environment
* Auto-evaluation using test cases
* Instant **Success / Fail** feedback
*  Confetti on success,  notifications on failure

###  Interview Experience

* 1-on-1 video interview rooms (Stream Video)
* Mic & camera toggle
* Screen sharing & recording
* Room locking (max 2 participants)

###  Real-Time Communication

* Live chat messaging powered by Stream
* Low-latency, scalable real-time infrastructure


* REST API with Node.js & Express
